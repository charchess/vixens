# Documentation archive

This directory contains historical documents that still have durable provenance value and are intentionally linked from active documentation.

Git history remains the primary archive for deleted reports, generated snapshots, temporary audits, and completed migration notes. Do not retain files here merely because they once existed.

Archived documents are **not normative**. Current behavior is defined by `WORKFLOW.md`, `AGENTS.md`, active reference documentation, workflows, manifests, and policies.
